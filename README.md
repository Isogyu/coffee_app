# ブラックエプロン試験クイズ

ブラックエプロン試験(スターバックス コーヒーマスター認定)の出題範囲を元にした
4択クイズアプリです。ビルド不要・依存なしの静的Webアプリです。

## 起動方法

`index.html` をブラウザで開くだけで動作します。

```bash
open index.html        # macOS
# またはローカルサーバーで:
python3 -m http.server 8000   # → http://localhost:8000
```

## 機能

- **4択クイズ + 解説** : 回答後すぐに正誤判定と解説を表示
- **スコア・進捗表示** : プログレスバー、結果画面で正解率を表示
- **カテゴリ別出題** : 7カテゴリから選んで集中対策
- **ランダム出題** : 全問からランダム10問
- **復習モード** : 間違えた問題を localStorage に蓄積し、再出題
  (正解すると復習対象から自動で外れます)

## 収録カテゴリ

| カテゴリ | 内容 |
|---|---|
| コーヒーの基礎知識 | コーヒーベルト、アラビカ/ロブスタ、収穫など |
| 生産地・原産国 | 3大生産地の風味特性、代表産地 |
| 精製方法と焙煎 | 水洗式/半水洗式/乾燥式、3段階ロースト |
| 抽出方法と鮮度 | プレス・エスプレッソ・ドリップ、保存方法 |
| テイスティング | 4ステップ、4要素、フードペアリング |
| コアコーヒー | ハウスブレンド、スマトラ、ケニアなど |
| スターバックスの歴史・理念 | 創業、ロゴ、C.A.F.E.プラクティスなど |

## 問題の追加方法

`questions.js` の `QUESTION_DATA` 配列に以下の形式で追加してください。

```js
{
  id: "unique-id",        // 一意なID(復習モードの管理に使用)
  category: "カテゴリ名",  // 既存 or 新規カテゴリ(自動でメニューに追加)
  question: "問題文",
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  answer: 0,              // 正解の選択肢のインデックス(0〜3)
  explanation: "解説文"
}
```

## ファイル構成

```
index.html    画面の骨格
style.css     コーヒーテーマのスタイル
app.js        クイズロジック・画面遷移・localStorage管理
questions.js  問題データ(50問)
```

## 注意

本アプリの問題は、実際の試験問題(非公開)ではなく、
一般的な出題範囲に基づくオリジナルの練習問題です。
